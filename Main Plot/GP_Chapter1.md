# 第一章

「黑屏」

第二天，因为家长的强烈坚持，医生被迫让我出了院。

「学校走廊画面」

「班主任办公室画面」

老师：（UserName）来上学啦？你妈妈说你有点发烧，现在好点没有？

我：……嗯，好多了，谢谢老师关心

原来她是这么欺骗老师的啊。。。

抑郁症是很羞于启齿的事情吗。。。？

老师：这几天的卷子我让班长整理好给你放桌洞里了

老师：对了，这个给你，上周发的期中成绩

我双手接下了成绩单

看到了意料之中的数字

「手中拿着成绩单」

下滑了啊……

这也是理所当然的罢。

最近上课、写题的时候完全集中不了注意力……

还经常犯困……

可是，这样回家的话……

「想起父母那丑恶的嘴脸」

我：……！

（指甲嵌进胳膊里）

「班主任办公室画面」

老师：（UserName）？你怎么了，身体不舒服吗？

我：没有……

老师：你之前一直都是班里十多名，这样的退步有点少见，家里是有什么事情吗？

我：……没有，都挺好的。

老师：不过你生病了肯定状态不好，咱们调整好状态，再接再厉

老师：最近先好好养身体，有事情一定要跟老师说

我强颜欢笑着点了点头，

努力抬起了灌了铅似的腿，走出了班主任办公室。

-----

「学校走廊画面」

身体……好沉重

家里那边怎么办……

好烦……好累……

周围充斥着同学的窃窃私语

宛如连空气都将我驱逐似的

同学甲：今天他怎么这副表情

同学乙：没考好呗，你没听老师刚才说的吗

果然又来了吗……

同学甲：这分其实也不低了

同学丙：听说他是抑郁症，是这个原因吧

呼吸……好困难……

选项：

	赶紧离开这里

同学乙：谁知道？

同学甲：是啊，在老师面前也是那种温顺的样子……

……

别说了……

我知道的，你们只是觉得我很讨厌吧……

还说我装温顺，觉得我恶心……

我远离了人群，但是嘈杂在我的耳中不但没有减少，反而越来越尖锐。

那些人说的话在我心中不断回响……

：我想考这分还考不到呢

：也不知道他在这装什么装

：就是，在老师面前装温顺，真恶心

：装的吧？真有精神病哪还能考这么好？

：他这是在炫耀吧

停下来……求求你们……

直到那微小的议论声化作了耳鸣的啸叫

「一阵耳鸣」

「画面变黑」

我颤抖着捂住耳朵，仿佛这样就能驱散那窃语一般。

-----

放学后，我回到了家。

「主角房间画面」

身上不知怎的，感觉无比疲倦。

（母亲板着脸推开门走进来）

母亲：别装死了，你们老师说考试成绩出来了，赶紧把成绩单给我看看

（你把成绩单递给了她）

母亲：班级第二十名？？？你可真给你娘涨脸啊，你在学校到底怎么学的啊！

母亲：你学习难道是给我学的吗！！？

说着，她扇了你一巴掌。

母亲：丢人现眼的玩意儿！养你那么多年白养了啊？！把吃的东西给我吐出来！

（母亲看向桌上的耳机）

母亲：一天到晚就知道听音乐听音乐，听傻了都不知道，拿过来！

（她一把抢走耳机）

母亲：下次考到年级前十再来找我要，我看你还敢不敢分心在这种东西上面！

说着，她生气地离开了我的房间。

。。。

。。

。

我捂着脸，两行清泪从眼角缓慢的滑下，手心一阵湿润，没有发出任何声音。

「画面模糊」

为什么？

因为我知道，哭出声的话又会被骂的。

说着什么“哭哭啼啼的像什么样子”。。。

我在这世上真就没人在乎吗？

就算是敷衍也好，就算是谎言也罢

哪怕称赞我、认可我一句呢……

为什么，为什么啊！

「画面恢复」

「画面颤抖」

你们每次总是拿我和别人比较！

而当我陈述你们的过错时，你们却只是淡淡的来一句：

你应该庆幸自己出生在一个开明的家庭。

你从哪看出来自己开明了？

难道是我求你们把我生下来的吗？

我不想当你们的孩子了……

我宁愿生到和谐的家庭

也不愿意让你们将我再次推向深渊！

-----

我把脸埋进枕头。

「画面变黑」

「插入CG」

此刻，我再次纵身跳入意识的河流……

河流如一只轻柔的手，拂过我的眼泪。

我的这颗心是如此的憔悴

我渴望就此长眠，

我渴望永远睡着看不见苦厄。

因为人性的丑恶，就算是罗生门的恶鬼也会畏惧。

何况是我呢。
