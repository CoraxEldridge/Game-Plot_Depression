# 第一章

[学校的走廊]

虽然医生极力劝阻，但父母还是叫我出院……

老师：（UserName）来啦？你妈妈说你有点发烧，现在好些了吗？

我：……嗯，好多了，谢谢老师关心。

果然，她只会觉得抑郁症羞于启齿。

老师：这几天的卷子，我让班长整理好，放你桌洞里了。

老师：对了，这个给你，上周发的月考成绩。

选项：接过成绩单

「纸张声音」

又下滑了啊……

倒也是意料之中。一边躯体化一边写题，能写好才怪。

*躯体化：躯体化（somatization）指个体将心理压力转化为躯体症状的现象，常见于抑郁症、焦虑症、疑病症及癔症等精神障碍。其核心特征为多系统躯体不适，包括头痛、胃痛及疲劳感等。

但是，回家的话……

「闪回：序章

我：……！

老师：（UserName）？怎么了，身体不舒服吗？

我：没有……

老师：毕竟有身体原因，咱们调整好状态，再接再厉，

我：好的，谢谢老师。

「脚步声，走廊嘈杂声」

身体又变得沉重了……

不仅没法给家里交代，这边也……

同学A：今天他怎么这副表情？

同学A：是因为什么……抑郁症吧。

同学B：谁知道真的假的。我听说真患者都不会让别人知道自己有病。

呼吸变得困难了……

同学B：而且他现在这分我还考不到呢，不知道在装什么……

别说了……
