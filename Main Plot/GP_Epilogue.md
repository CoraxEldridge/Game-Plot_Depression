# 终章

（画面：黑屏）

内心独白：自上次跟小夜约会后，我们在学校的交集比以前更多了

内心独白：小夜她总是在为他人着想，帮助别人。她也很照顾我。

（画面：学校天台·黑白）

内心独白：好像是前几天的事情吧，这件事被我在心里一遍又一遍的回味。

内心独白：我无意间跟小夜提起自己晚上总是失眠的事情。

内心独白：虽然只是个小事，但她还是默默记住了。

（画面：学校天台·色彩恢复）

内心独白：第二天小夜叫我去天台，我便过去了。

内心独白：来到天台的时候，看到她担心的神色，我还有些疑惑。

（画面：薰衣草茶茶包）

内心独白：她从手提袋里拿出一盒薰衣草茶。

赵夜清：你最近似乎总是失眠呢。

赵夜清：我给你买了一盒助眠的花茶，睡前喝点这个应该能改善一下睡眠。

内心独白：小夜跟我提了许多对失眠有帮助的建议。

内心独白：我很感谢她这么为我考虑，也很高兴。

内心独白：明明只是无意间提起的事，她却记住了，还对我施以帮助。

（画面：学校天台·黑白）

内心独白：可是，小夜的心意没能将我的失眠战胜。

内心独白：次日，一如既往的天台。

内心独白：她问我失眠有没有缓解，我便如实相告。

内心独白：小夜沮丧地低下头，沉默了一会。

赵夜清：我又什么都没做到，连帮忙都帮不上……

我：没事的，这不是小夜你的问题

我：有小夜你的这份心意在，就已经很令人安心了

赵夜清：为什么，明明我什么都没做、什么忙都没帮上……

我：你的存在本身，就能够给我带来努力生活的勇气了。

赵夜清：我的存在本身……？

我：是的，无论何时何地，想起你的时候总是感觉很温暖，给我带来勇气。

我：自从遇见你，我在这世上的牵挂便多了一个。

赵夜清：是吗……

赵夜清：谢谢你，我似乎明白一些了。

我：是吗？那就太好了！

（画面：逐渐变暗直至黑屏）

内心独白：在那之后，小夜也尝试着约我出来玩，试着去做一些自己想做的事情。

内心独白：可能是因为运动量多了一点的缘故，后来我的失眠就好多了

（画面：街道）

内心独白：最后一次约会结束时，她向我坦露了自己的心声。

赵夜清：以前我总把自己放在「拯救者」这个位置上，妄图拯救他人。

赵夜清：但是因为有你，我才发现世间的一些很小的美好与幸福，才发现生活中的那些独特的色彩。

赵夜清：虽然我一直认为自己是个不合格的「拯救者」。

赵夜清：但是，因为你的出现，我才知道作为一个人就已经可以被好好接纳着。

赵夜清：人是目的，不是手段。

赵夜清：谢谢你让我明白这些。

（画面：黑屏）

内心独白：在心里反复回味着这些话，每次都有新的感受。

内心独白：我们对彼此，都是很特别、很重要的存在。

-----

（画面：黑屏）

内心独白：…………

内心独白：………………！

（画面：卧室）

旁白：「卧室」

内心独白：做了一个……很可怕的噩梦……

内心独白：睡衣背后全都被冷汗浸湿。

内心独白：但我却想不起梦的内容……

内心独白：算了，还是赶紧起床去洗漱吧。

（画面：黑屏）

内心独白：去学校之前，我都心不在焉的。

（画面：学校楼梯间）

内心独白：不知不觉就想去天台放松一下，即使小夜没在这里。

内心独白：偶尔看看日出也挺不错的。

（画面：学校天台·黎明时分）

旁白：「天台」

内心独白：来到学校天台，却让我发现了意外的身影。

内心独白：赵夜清

内心独白：她似乎注意到我来了，朝我招了招手

内心独白：她唤我过去，我便走到她身旁。

我：早上好，小夜

赵夜清：你也是哦，早上好。

赵夜清：不过看你的脸色……

赵夜清：是不是发生了什么不好的事？

我：……做噩梦了。

内心独白：她露出一副“原来如此”的表情。

赵夜清：是怎样的梦呢？

我：记不起来了，大概是跟家里有关吧……

我：不过没事的，这些小事忍耐一下就过去了，不用担心。

（画面：日出）
内心独白：随后我便转过身去看缓缓升起的朝阳。

内心独白：正当我以为这个话题已经结束了的时候。

内心独白：我的背后感受到了轻柔的温暖

内心独白：稍微转头，才发现小夜从后面抱住了我。

我：你在干嘛？

赵夜清：唔……没什么啦，只是突然想抱抱你。

赵夜清：会困扰吗？

我：不会。

我：……谢谢你

赵夜清：欸。不用道谢也没关系哦，我只是突然间想感受一下人的温暖罢了。

我：那也谢谢你

内心独白：小夜分明就是在安慰我，但还说成是她自己想要的。

内心独白：早春时候的柳树枝条已然开始长出新芽。

内心独白：分明这时天气还没那么暖和。

内心独白：但是……

内心独白：感觉，从我的内心深处，渐渐涌出一股暖意。

内心独白：熙熙攘攘的街道，公园里晨练的老人，整座城市都在慢慢醒来。

内心独白：我扭头望向她的脸。

内心独白：她似乎感受到我的视线，也望了过来。

内心独白：眼神交汇的瞬间，我呼吸一滞。

内心独白：晨风轻拂脸庞，吹动校服下摆，吹起了小夜那柔顺的长发。

（音频：心跳声）

内心独白：非常神奇，这是我从未有过的感受。

内心独白：心脏跳动的幅度有些不正常。

内心独白：内心痒痒的，好像有千万话语堵在胸膛。

内心独白：我先红了脸，迅速别开了头。

内心独白：即使如此，我还是用余光看着她。

内心独白：她的脸也微微泛着红晕。

内心独白：我们就这样一言不发，谁都不敢看对方，这样僵持了许久。

内心独白：赵夜清大抵是想主动打破沉默罢。

赵夜清：感觉，认识你，真好。

内心独白：眼波流转，色彩随微小的眼动于眸中浮游。

内心独白：我会心一笑。

我：我也是，如果没有你，我甚至活不到现在。

我：正是因为有你，我那原本单薄、黯淡的生活，才变得有趣起来

我：因为有你，我才知道心不光可以用来感受痛苦，还可以用来感受幸福。

我：因为有你，我才意识到生活中有那么多美好的事物。

我：真的，非常感谢。

内心独白：赵夜清思索了几秒，脸上泛起一丝不易察觉的红晕，连耳尖都有些泛红。

赵夜清：唔……

内心独白：过了一小会，她故作平静地轻咳几声。

赵夜清：我也该谢谢你。

我：这次的小夜，是什么感受？

赵夜清：这次想要以真正的朋友的身份，站在此地。

赵夜清：愿你幸福，愿你也相信自己能够得到幸福。

我：我也愿你能够幸福，也希望我的存在可以帮助你感知到幸福。

赵夜清：我也是哦，我也想为你带来幸福。

内心独白：早晨的太阳总是那么的耀眼，空气总是那么清新。

（音频：上课铃）

我：打上课铃了呢

赵夜清：是呀，我们回去吧。

「我们牵着手，走了下去。」
