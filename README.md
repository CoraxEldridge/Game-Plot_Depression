## 格式说明

### 文件名格式

GP为Game Plot（游戏剧情）缩写

### 内容格式

「」为场景表演

（UserName）为玩家昵称

分割线（-----）为场景切换

引用语法（>）为选项内容

加粗（\*\*\*\*）、斜体（\*\*）以及加粗斜体（\*\*\*\*\*\*）为特殊内容

星号（*）后为注释
